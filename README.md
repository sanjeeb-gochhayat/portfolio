# Sanjeeb Gochhayat — 3D Personal Portfolio Website

A cinematic, futuristic, and high-performance **3D personal portfolio website** designed and engineered with **React 19, TypeScript, Three.js / React Three Fiber, Drei, Tailwind CSS, and Framer Motion**.

---

## ✨ Features & Architecture

- **Cinematic 3D Hero Scene**: Floating abstract workstation environment with wireframe gyroscopes, refractive glass syntax fragments, and interactive mouse parallax.
- **3D About Assembler**: Multi-layer interface stack (State Engine, Component Tree, Visual Polish) with interactive 3D rotation and exploded inspection.
- **3D Skill Constellation Galaxy**: Interconnected orbital nodes revolving around a central *Frontend Engineering Core* with real-time hover inspection and category filters.
- **Cinematic Project Gallery & Case Study Modals**:
  - 3D tilt cards with cursor-tracking specular glare.
  - Bespoke live visual preview mocks (interactive UI tokens, streaming telemetry waveform, WebGL shader prism, AST runtime tree).
  - Immersive full-screen case-study drawers detailing Problem Solved, Engineering Contribution, Technical Challenges, Architecture Patterns, and Measured Impact.
- **"How I Think" Technical Showcase**:
  - **React Rendering Simulator**: Interactive component tree showing parent-to-child re-render cascades vs `React.memo` prop memoization.
  - **Performance & Virtualization Benchmarker**: Live slider comparing 10,000 unvirtualized DOM nodes against windowed virtualization.
  - **Component Architecture**: Atomic design layer explorer (Tokens → Atoms → Molecules → Organisms).
  - **6-Stage Problem Solving Pipeline**: Step-by-step real-world case study (Search Debounce & AbortController).
- **Interactive CS & DSA Lab**:
  - **Binary Search Stepper**: Visual step-by-step array halving with `low`, `mid`, and `high` pointer tracking.
  - **BST Traversal Simulator**: Animated node visit runner for In-Order, Pre-Order, and Post-Order traversals.
  - **Complexity Matrix**: Big-O breakdown and clean TypeScript implementations.
- **"Code Meets Creativity" Visual Gallery**:
  - Visual storytelling, UI token design, and interactive 4-pass Photoshop layer compositing studio.
- **Dramatic Contact Hub**:
  - Reactive 3D glowing energy orb.
  - One-click copy email to clipboard with animated feedback.
  - Direct social links (GitHub, LinkedIn, Twitter/X).
  - Interactive contact dispatch form with celebratory confetti physics.
- **Micro-Interactions**:
  - Custom lerped magnetic cursor (desktop fine pointer).
  - Magnetic spring physics CTAs.
  - Top scroll progress indicator.
  - Dynamic local time clock.
  - Full mobile responsiveness and `prefers-reduced-motion` compliance.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```

## 🛠 Customization Guide

All personal data, links, and content are centralized in `src/data/` for effortless updating:

| File | What to Customize |
|---|---|
| `src/data/portfolioData.ts` | Headline, bio, email, social profile URLs, journey timeline milestones, creative works |
| `src/data/projectsData.ts` | Project case studies, live demo links, repository URLs, architectural highlights |
| `src/data/skillsData.ts` | Skill ratings, constellation 3D coordinates, categories, competencies |
| `src/data/dsaData.ts` | Algorithmic concepts, code snippets, complexity ratings |
